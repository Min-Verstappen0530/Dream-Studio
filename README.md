# Minecraft-mods
Dream Studio adds interchangeable-lens cameras to Minecraft Java Edition. Grab a camera body and lens from the Dream Studio creative tab, hold the body, and use the Camera Assembly keybind to mount the lens. Frame your shot on the rear screen or through the electronic viewfinder, then adjust shutter speed, aperture, ISO, and focus.

There are two camera bodies and six lenses, from ultrawide to supertelephoto. Each lens has its own depth of field, bokeh, distortion, vignetting, and color fringing. The mod also simulates sensor noise. You can save photos as PNG or open the DNG RAW files in a RAW editor to adjust exposure, white balance, and color.

The Minecraft 26.3 build requires Java 25+, Fabric Loader 0.19.3+, and Fabric API 0.160.5+26.3. Iris is optional and requires Loader 0.19.4+ if you use Iris 1.11.5 or later. Shader capture was tested with Iris 1.11.7 and Sodium 0.9.2. The mod includes capture profiles for Ray 0.1.0a0-5aa85e9 nightly, Complementary Reimagined and Unbound r5.10, Photon v1.4, BSL v10.1.8, Bliss v2.1.2, AstraLex V93.0, Derivative 26.3, MakeUp Ultra Fast 9.6, Sildur’s Vibrant Shaders v2.02 Extreme, and Solas v3.9.

Both Minecraft 1.21.1 builds require Java 21+, Fabric Loader 0.16.5+, and Fabric API 0.116.10+1.21.1 or a later release for 1.21.1. The standard build works with vanilla rendering or with Iris 1.8.8 and Sodium 0.6.13. The separate Java RTX Remix build requires rtx-remix-renderer version 0.1.1-202611060211-7d2ba9f and is incompatible with Iris and Sodium.

梦幻摄影在 Minecraft Java 版里加入了可换镜头的相机。从创造模式的 梦幻摄影 标签页拿到机身和镜头，手持机身，按 相机装配 快捷键安装镜头。拍照时可以用背屏或电子取景器构图，再调节快门、光圈、ISO 和焦点。

模组提供两台机身和六支镜头，覆盖超广角到超长焦。每支镜头的景深、焦外光斑、畸变、暗角和色差各有特点，拍摄时也会模拟传感器噪声。照片可以保存为 PNG 或 DNG RAW，后者可以在 RAW 编辑器里继续调整曝光、白平衡和颜色。

Minecraft 26.3 版需要 Java 25+、Fabric Loader 0.19.3+ 和 Fabric API 0.160.5+26.3。Iris 可选装，使用 Iris 1.11.5 或更高版本时需要 Loader 0.19.4+。光影拍摄在 Iris 1.11.7 和 Sodium 0.9.2 下测试。模组为以下光影适配了拍摄设置：Ray 0.1.0a0-5aa85e9 nightly、Complementary Reimagined 和 Unbound r5.10、Photon v1.4、BSL v10.1.8、Bliss v2.1.2、AstraLex V93.0、Derivative 26.3、MakeUp Ultra Fast 9.6、Sildur’s Vibrant Shaders v2.02 Extreme 和 Solas v3.9。

两个 Minecraft 1.21.1 构建都需要 Java 21+、Fabric Loader 0.16.5+，以及 Fabric API 0.116.10+1.21.1 或更新的 1.21.1 对应版。常规版支持原版渲染，也可搭配 Iris 1.8.8 和 Sodium 0.6.13。独立的 Java RTX Remix 版需要 rtx-remix-renderer 0.1.1-202611060211-7d2ba9f，与 Iris 和 Sodium 不兼容。
